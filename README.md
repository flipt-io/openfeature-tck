# flipt-io/openfeature-tck

A shared Flipt backend for the OpenFeature Provider TCK.

```text
ghcr.io/flipt-io/openfeature-tck:0.1.0
```

The image runs on `linux/amd64` and is built on
`docker.flipt.io/flipt/flipt:v2`.

The `spec` module embeds the Flipt vendor scenarios for the Go adoption. See
`spec/README.md`.
